# What Video Game Type Are You?

A five-question personality quiz with four possible results: Survival, Shooter, Story Mode, and Open World.

Open `index.html` in a browser or with Live Server. Choose one answer for each question, then click **Show Results**. The result appears on the page without reloading it.

Built with HTML, CSS, JavaScript, and Bootstrap.
